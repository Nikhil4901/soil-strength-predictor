# Soil Strength Predictor

Machine Learning-based prediction of:

- California Bearing Ratio (CBR)
- Unconfined Compressive Strength (UCS)

## Features
- Predict CBR values
- Predict UCS values
- GUI-based interface
- Trained ML models saved as PKL files

## Files
- model_cbr.pkl
- model_ucs.pkl
- scaler.pkl
- GUI.py

## Installation

pip install -r requirements.txt

## Run

python GUI.py
